This library is published at https://test.pypi.org/project/astronomy-research-team16/.

The library API is a comprehensive tool to query astronomical data from SDSS, build classification models for predicting stars, galaxies, and QSOs. This [API](https://code.harvard.edu/CS107/team16_2023/blob/dev/API_draft/API_draft.md) provides a wide range of functionalities organized into several modules to facilitate data retrieval, preprocessing, metadata extraction, wavelength alignment, visualization, data augmentation, machine learning, and spectral feature extraction.
